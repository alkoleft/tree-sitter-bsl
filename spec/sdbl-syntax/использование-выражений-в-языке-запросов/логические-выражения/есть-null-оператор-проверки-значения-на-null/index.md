# Оператор проверки значения на NULL

Оператор **ЕСТЬ NULL** позволяет проверить значение выражения слева от него на [NULL](../../../ключевые-слова-и-функции/константы-и-параметры-значение/null/index.md). Если значение равно [NULL](../../../ключевые-слова-и-функции/константы-и-параметры-значение/null/index.md) – результатом оператора будет [ИСТИНА](../../../ключевые-слова-и-функции/константы-и-параметры-значение/истина/index.md), иначе – [ЛОЖЬ](../../../ключевые-слова-и-функции/константы-и-параметры-значение/ложь/index.md). Применение **НЕ** изменяет действие оператора на обратное.

> **см. также: **[Логические выражения](../index.md)

#### Пример:

```sdbl
ВЫБРАТЬ
   Справочник.Номенклатура.Наименование,
   Справочник.Номенклатура.ЗакупочнаяЦена
ГДЕ
   Справочник.Номенклатура.ЗакупочнаяЦена Есть NULL
```
