# Оператор проверки вхождения значения в диапазон

Оператор **МЕЖДУ** позволяет проверить, входит ли значение выражения, указанного справа от него, в диапазон, указанный слева (вместе с границами диапазона). Если входит – результатом оператора будет [ИСТИНА](../../../ключевые-слова-и-функции/константы-и-параметры-значение/истина/index.md), иначе – [ЛОЖЬ](../../../ключевые-слова-и-функции/константы-и-параметры-значение/ложь/index.md). Применение **НЕ** изменяет действие оператора на обратное. Сравнение значений производится по [правилам сравнения значений](../операция-сравнения/правила-сравнения-значений/index.md).

#### Пример:

```sdbl
ВЫБРАТЬ
   Справочник.Номенклатура.Наименование,
   Справочник.Номенклатура.ЗакупочнаяЦена
ГДЕ
   Справочник.Номенклатура.ЗакупочнаяЦена МЕЖДУ 100 И 1000
```
