# Оператор проверки ссылочного значения

Оператор **ССЫЛКА** позволяет проверить, является ли значение выражения, указанного справа от него, ссылкой на таблицу, указанную слева. Если да – результатом оператора будет [ИСТИНА](../../../ключевые-слова-и-функции/константы-и-параметры-значение/истина/index.md), иначе – [ЛОЖЬ](../../../ключевые-слова-и-функции/константы-и-параметры-значение/ложь/index.md). Разыменование таблиц описано в главе [Разыменование полей](../../разыменование-полей/index.md).

> **см. также: **[Логические выражения](../index.md)

#### Пример:

```sdbl
ВЫБРАТЬ
   Справочник.Номенклатура.Наименование,
   Справочник.Номенклатура.ЕдиницаИзмерения
ГДЕ
   Справочник.Номенклатура.ЕдиницаИзмерения ССЫЛКА Справочник.ЕдиницыИзмерения
```
