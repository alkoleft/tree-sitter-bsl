# Правила сравнения значений

Поскольку в языке запросов могут сравниваться значения разных типов, определены правила, по которым выполняется сравнение двух значений. Данные правила используются для:

- сравнения значений в операторах сравнения;

- определения максимального и минимального значений в агрегатных функциях [МИНИМУМ](../../../агрегатные-функции/минимум/index.md) и [МАКСИМУМ](../../../агрегатные-функции/максимум/index.md);

- упорядочивания записей результата запроса в соответствии с порядком, заданным в предложении [УПОРЯДОЧИТЬ ПО](../../../../текст-запроса/секция-упорядочить-по-упорядочивание-результатов/index.md).

Если типы значений отличаются друг от друга, то отношения между значениями определяются на основании приоритета типов:

- тип [NULL](../../../../ключевые-слова-и-функции/константы-и-параметры-значение/null/index.md) (самый низший);

- тип Булево;

- тип [ЧИСЛО](../../../../ключевые-слова-и-функции/константы-и-параметры-значение/литерал-типа-число/index.md);

- тип [ДАТА](../../../../ключевые-слова-и-функции/прочее/датавремя/index.md);

- тип [СТРОКА](../../../../ключевые-слова-и-функции/константы-и-параметры-значение/литерал-типа-строка/index.md);

- ссылочные типы.

Отношения между различными ссылочными типами определяются на основе внутренних ссылочных номеров таблиц, соответствующих тому или иному типу.

Если типы данных совпадают, то производится сравнение значений по следующим правилам:

- у типа Булево значение [ИСТИНА](../../../../ключевые-слова-и-функции/константы-и-параметры-значение/истина/index.md) больше значения [ЛОЖЬ](../../../../ключевые-слова-и-функции/константы-и-параметры-значение/ложь/index.md);

- у типа [ЧИСЛО](../../../../ключевые-слова-и-функции/константы-и-параметры-значение/литерал-типа-число/index.md) обычные правила сравнения для чисел;

- у типа [ДАТА](../../../../ключевые-слова-и-функции/прочее/датавремя/index.md) более ранние даты меньше более поздних;

- у типа [СТРОКА](../../../../ключевые-слова-и-функции/константы-и-параметры-значение/литерал-типа-строка/index.md) сравнения производится в соответствии с установленными национальными особенностями базы данных;

- ссылочные типы сравниваются на основе своих значений (номера записи и т. п.);

- для массивов выполняется последовательное сравнение элементов массива;

- для таблиц значений выполняется последовательное сравнение элементов таблиц;

- для объектов не примитивного типа, не ссылочных типов, не явлющихся массивом или таблицей значний:


  - При упорядочивании сравнение выполняется по строковому представлению сравниваемых объектов.

  - При сравнении с использованием операторов **=** и **<>**, выполняется проверка на то, что объект сравнивается сам с собой.

  - При сравнении с использованием операторов **<**, **<=**, **>**  и **>=** генерируется исключение "Попытка сравнения не сравниваемых значений".
Например: если в группировке происходит упорядочивание по функции** ВычислитьВыражениеСГруппировкойМассив ("Сумма(СуммаОборот)", "Контрагент"))** то упорядочивание при формировании отчета всегда будет одинаковым – по содержимому полученных массивов.
- не допускается сравнение полей неограниченной длины (строки неограниченной длины, ХранилищеЗначения, поле [ТИПЗНАЧЕНИЯ](../../../функции-языка-запросов/типзначения/index.md) из таблицы планов видов характеристик).

**Важно!** Любая операция сравнения двух значений, в которой участвует хотя бы одно значение [NULL](../../../../ключевые-слова-и-функции/константы-и-параметры-значение/null/index.md), дает результат, аналогичный значению [ЛОЖЬ](../../../../ключевые-слова-и-функции/константы-и-параметры-значение/ложь/index.md).
