# Бинарные операции

Бинарными (арифметическими) операциями являются операции:

> **+ **|** – **|** * **|** /  **

Бинарные операции используются для типов [ЧИСЛО](../../ключевые-слова-и-функции/константы-и-параметры-значение/литерал-типа-число/index.md).

Для типа [СТРОКА](../../ключевые-слова-и-функции/константы-и-параметры-значение/литерал-типа-строка/index.md) может использоваться бинарная операция **+**.
