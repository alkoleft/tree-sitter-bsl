# Использование выражений в языке запросов

Во многих конструкциях языка запросов могут использоваться выражения. Выражения языка запросов описываются следующим набором правил:

**

**
****
****
**| <Выражение> |                                                                                                                                                                                                                                                            |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|             | \|                                                                                                                                                                                                                                                         |
|             | <Разыменование поля> \| <Агрегатная функция> \| <Функция языка запросов> \| <Операция выбора> \|<Приведение типа>[.<Разыменование поля>] \| <Значение> \| <Выражение> <Бинарная операция> <Выражение> \| <Унарная операция> <Выражение> \| ( <Выражение> ) |


**В простейшем случае выражение является ссылкой на поле исходной таблицы – [источника данных запроса](../текст-запроса/секция-выбрать-описание-запроса/предложение-из/index.md). Ссылка может задаваться с указанием таблицы, содержащей это поле, или без указания самой таблицы. О правилах указания полей таблиц смотрите в главе [Разыменование полей](разыменование-полей/index.md).

Выражения в [списке полей выборки](../текст-запроса/секция-выбрать-описание-запроса/предложение-выбрать/список-полей-выборки/index.md), в предложениях [ИМЕЮЩИЕ](../текст-запроса/секция-выбрать-описание-запроса/предложение-имеющие/index.md), [ИТОГИ](../текст-запроса/секция-итоги-описание-итогов/index.md), [УПОРЯДОЧИТЬ ПО](../текст-запроса/секция-упорядочить-по-упорядочивание-результатов/index.md) могут быть [агрегатными функциями](агрегатные-функции/index.md).

Выражение может быть [функцией языка запросов](функции-языка-запросов/index.md). Могут использоваться [операции выбора](операция-выбора-выбор/index.md), и операции [приведения типа значения](приведение-типа-выразить/index.md).

В выражениях могут непосредственно указываться значения [логических, числовых, строковых и др. констант](../ключевые-слова-и-функции/константы-и-параметры-значение/index.md); также могут использоваться значения [параметров запроса](../ключевые-слова-и-функции/константы-и-параметры-значение/имя-параметра/index.md). В выражениях к значениям соответствующих типов могут применяться [бинарные](бинарные-операции/index.md) и [унарные](унарные-операции/index.md) операции.

**Ограничения**:
Максимальная длина цепочки операций одного приоритета не должна превышать 2048, например: v1 + v2 + v3 + ... + v2048.
Максимальное количество вложенных друг в друга операций разного приоритета, включая скобки, не должно превышать 2048.
