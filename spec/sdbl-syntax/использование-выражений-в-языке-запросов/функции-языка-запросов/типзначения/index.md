# Функция ТИПЗНАЧЕНИЯ

Функция определения типа значения в запросе.

Параметры функции:

> Параметр — выражение любого типа

Возвращаемое значение: тип значения.

**Пример:**

> ВЫБРАТЬ ТИПЗНАЧЕНИЯ(Продажи.Регистратор)
> ИЗ РегистрНакопления.Продажи КАК Продажи
>
>
>
