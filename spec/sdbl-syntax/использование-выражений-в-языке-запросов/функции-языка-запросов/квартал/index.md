# Функция КВАРТАЛ

Данная функция предназначена для вычисления номера квартала из значения типа [ДАТА](../../../ключевые-слова-и-функции/прочее/датавремя/index.md). Номер квартала находится в диапазоне 1 – 4.

Параметр функции – это выражение, имеющее тип [ДАТА](../../../ключевые-слова-и-функции/прочее/датавремя/index.md).

Если в качестве параметра фигурирует значение типа Дата, то результатом функции будет значение типа [ЧИСЛО](../../../ключевые-слова-и-функции/константы-и-параметры-значение/литерал-типа-число/index.md). Если в качестве параметра будет использовано значение [NULL](../../../ключевые-слова-и-функции/константы-и-параметры-значение/null/index.md), то результатом функции также будет значение [NULL](../../../ключевые-слова-и-функции/константы-и-параметры-значение/null/index.md). Другие значения считаются недопустимыми и приводят к ошибке исполнения запроса.

> **см. также:** [Функции языка запросов](../index.md)
