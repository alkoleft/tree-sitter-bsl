# Функция МИНУТА

Данная функция предназначена для вычисления минуты часа из значения типа [ДАТА](../../../ключевые-слова-и-функции/прочее/датавремя/index.md). Минута часа находится в диапазоне 0 – 59.

Параметр функции – это выражение, имеющее тип [ДАТА](../../../ключевые-слова-и-функции/прочее/датавремя/index.md).

Если в качестве параметра фигурирует значение типа [ДАТА](../../../ключевые-слова-и-функции/прочее/датавремя/index.md), то результатом функции будет значение типа [ЧИСЛО](../../../ключевые-слова-и-функции/константы-и-параметры-значение/литерал-типа-число/index.md). Если в качестве параметра будет использовано значение [NULL](../../../ключевые-слова-и-функции/константы-и-параметры-значение/null/index.md), то результатом функции также будет значение [NULL](../../../ключевые-слова-и-функции/константы-и-параметры-значение/null/index.md). Другие значения считаются недопустимыми и приводят к ошибке исполнения запроса.
