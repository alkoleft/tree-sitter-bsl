# Функция ДЕНЬНЕДЕЛИ

Данная функция предназначена для вычисления дня недели из значения типа [ДАТА](../../../прочее/датавремя/index.md). День недели находится в диапазоне 1 (понедельник) – 7 (воскресенье).

Параметр функции – это выражение, имеющее тип [ДАТА](../../../прочее/датавремя/index.md).

Если в качестве параметра фигурирует значение типа [ДАТА](../../../прочее/датавремя/index.md), то результатом функции будет значение типа [ЧИСЛО](../../../константы-и-параметры-значение/литерал-типа-число/index.md). Если в качестве параметра будет использовано значение [NULL](../../../константы-и-параметры-значение/null/index.md), то результатом функции также будет значение [NULL](../../../константы-и-параметры-значение/null/index.md). Другие значения считаются недопустимыми и приводят к ошибке исполнения запроса.
