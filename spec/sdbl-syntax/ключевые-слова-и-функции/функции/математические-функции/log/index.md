# Функция Log

```
Log (<Число>)
```

Данная функция вычисляет натуральный логарифм числа.

> **Число **- [Число](../../../константы-и-параметры-значение/литерал-типа-число/index.md) (длина - 12, точность - 9).

**Возвращаемое значение:** [Число](../../../константы-и-параметры-значение/литерал-типа-число/index.md).

**Внимание!** При использовании в запросе данной функции запрос не будет передан в Дата акселератор.


> **см. также:** [Функции языка запросов](../../../../использование-выражений-в-языке-запросов/функции-языка-запросов/index.md)
