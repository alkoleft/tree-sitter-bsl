# Функция Exp

```
Exp (<Число>)
```

Данная функция вычисляет результат возведения основания натурального логарифма (числа e) в степень.

> **Число **- [Число](../../../константы-и-параметры-значение/литерал-типа-число/index.md).

**Возвращаемое значение:** [Число](../../../константы-и-параметры-значение/литерал-типа-число/index.md) (длина - 38, точность - 9).

**Внимание!** При использовании в запросе данной функции запрос не будет передан в Дата акселератор.


> **см. также:** [Функции языка запросов](../../../../использование-выражений-в-языке-запросов/функции-языка-запросов/index.md)
