# Функция ACos

```
ACos (<Число>)
```

Данная функция вычисляет арккосинус в радианах.

> **Число **- [Число](../../../константы-и-параметры-значение/литерал-типа-число/index.md) в диапазоне -1...1.

**Возвращаемое значение:** [Число](../../../константы-и-параметры-значение/литерал-типа-число/index.md) (длина - 10, точность - 9) .


**Внимание!** При использовании в запросе данной функции запрос не будет передан в Дата акселератор.


> **см. также:** [Функции языка запросов](../../../../использование-выражений-в-языке-запросов/функции-языка-запросов/index.md)
