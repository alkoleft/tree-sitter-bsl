# Функция Pow

```
Pow(<Основание>, <Показатель>)
```

Данная функция возводит значение **Основание** в степень.

> **Основание **- [Число](../../../константы-и-параметры-значение/литерал-типа-число/index.md).
>
> **Степень **- [Число](../../../константы-и-параметры-значение/литерал-типа-число/index.md).

**Возвращаемое значение:** [Число](../../../константы-и-параметры-значение/литерал-типа-число/index.md) (Длина - 38, точность - исходная точность + 6 знаков, но не больше 9, если исходная точность меньше 9).

**Внимание!** При использовании в запросе данной функции запрос не будет передан в Дата акселератор.
