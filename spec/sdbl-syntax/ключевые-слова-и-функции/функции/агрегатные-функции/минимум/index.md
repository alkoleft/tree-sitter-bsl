# Агрегатная функция МИНИМУМ

Функция вычисляет минимальное значение из всех попавших в выборку значений поля.

В качестве параметра функции можно указывать выражения, содержащие значения любого типа. Не может применяться к выражениям с типом ХранилищеЗначения и Строкам неограниченной длины.

При определении минимального значения применяются правила сравнения значений, описанные в [Правила сравнения значений](../../../../использование-выражений-в-языке-запросов/логические-выражения/index.md#CompareRules).
