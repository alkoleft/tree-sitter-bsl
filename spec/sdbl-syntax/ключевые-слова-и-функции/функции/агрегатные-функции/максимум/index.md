# Агрегатная функция МАКСИМУМ

Функция вычисляет максимальное значение из всех попавших в выборку значений поля.

В качестве параметра функции можно указывать выражения, содержащие значения любого типа. Не может применяться к выражениям с типам ХранилищеЗначения и МоментВремени, а также Строкам неограниченной длины .

При определении максимального значения применяются правила сравнения значений, описанные в [Правила сравнения значений](../../../../использование-выражений-в-языке-запросов/логические-выражения/index.md#CompareRules).
