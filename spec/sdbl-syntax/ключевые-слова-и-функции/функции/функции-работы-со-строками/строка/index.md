# Функция Строка (String)

```
СТРОКА (<Значение>)
```

Данная функция преобразует значение примитивного типа в строку с учетом национальных установок.

При применении к не примитивному типу выдается ошибка при попытке выполнения запроса. Если в качестве параметра будет использовано значение [NULL](../../../константы-и-параметры-значение/null/index.md), то результатом функции также будет значение [NULL](../../../константы-и-параметры-значение/null/index.md).

> **Значение** - преобразуемое значение типа [Число](../../../константы-и-параметры-значение/литерал-типа-число/index.md), Булево, [Строка](../../../константы-и-параметры-значение/литерал-типа-строка/index.md), [Дата](../../../прочее/датавремя/index.md), [NULL](../../../константы-и-параметры-значение/null/index.md), [Неопределено](../../../константы-и-параметры-значение/неопределено/index.md).

**Возвращаемое значение:** [Строка](../../../константы-и-параметры-значение/литерал-типа-строка/index.md).
Длина результирующей строки определяется на основании значения:

- Для [Числа](../../../константы-и-параметры-значение/литерал-типа-число/index.md) - длина строки равна длине числа умноженной на 2.

- Для [Дата](../../../прочее/датавремя/index.md) и Булево длина строки равна 32.

- Для [NULL](../../../константы-и-параметры-значение/null/index.md) и [Неопределено](../../../константы-и-параметры-значение/неопределено/index.md) длина строки равна 1.
