# Функция ДлинаСтроки (StringLength)

```
ДлинаСтроки(<Строка>)
```

Данная функция получает длину строки.

> **Строка **- [Строка](../../../константы-и-параметры-значение/литерал-типа-строка/index.md). Строка, длину, которой нужно получить.

**Возвращаемое значение:** [Число](../../../константы-и-параметры-значение/литерал-типа-число/index.md) (длина - 12).

**Внимание!** При использовании в запросе данной функции запрос не будет передан в Дата акселератор.


> **см. также:** [Функции языка запросов](../../../../использование-выражений-в-языке-запросов/функции-языка-запросов/index.md)
