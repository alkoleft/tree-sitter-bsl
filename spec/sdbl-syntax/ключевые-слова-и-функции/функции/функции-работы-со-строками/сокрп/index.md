# Функция СокрП (TrimR)

```
СокрП(<Строка>)
```

Данная функция отсекает незначащие символы, стоящие справа от последнего значащего символа в строке.

> **Строка **- [Строка](../../../константы-и-параметры-значение/литерал-типа-строка/index.md). Исходная строка.

**Возвращаемое значение:** [Строка](../../../константы-и-параметры-значение/литерал-типа-строка/index.md). Строка, полученная в результате отсечения пробелов.

**Внимание!** При использовании в запросе данной функции запрос не будет передан в Дата акселератор.


> **см. также:** [Функции языка запросов](../../../../использование-выражений-в-языке-запросов/функции-языка-запросов/index.md)
