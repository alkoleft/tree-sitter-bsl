# Функция СтрНайти(StrFind)

```
СтрНайти(<Строка>, <ПодстрокаПоиска>)
```

Данная функция находит первое вхождение искомой строки как подстроки в исходной строке. Поиск выполняется без учета регистра.

> **Строка **- [Строка](../../../константы-и-параметры-значение/литерал-типа-строка/index.md). Исходная строка.
>
> **ПодстрокаПоиска **- [Строка](../../../константы-и-параметры-значение/литерал-типа-строка/index.md). Искомая подстрока.

**Возвращаемое значение:** [Число](../../../константы-и-параметры-значение/литерал-типа-число/index.md) (длина - 12). Найденная позиция, начиная с 1. Если возвращает 0, то строка не найдена.

**Внимание!** При использовании в запросе данной функции запрос не будет передан в Дата акселератор.
