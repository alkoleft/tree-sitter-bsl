# Функция СГРУППИРОВАНОПО

СГРУППИРОВАНОПО (<Выражение>)

> <Выражение> – столбец или выражение, которое содержит столбец в предложении [СГРУППИРОВАТЬ ПО](../../../../текст-запроса/секция-выбрать-описание-запроса/предложение-сгруппировать-по/index.md).

Функция предназначена для различения наборов, по которым ведется группировка.

**Возвращаемое значение:**

Функция возвращает **ИСТИНА** для записей, которые были получены для группировки по этому полю (одному или с другими полями).

Функция возвращает **ЛОЖЬ** для записей, которые не были получены для группировки по этому полю.

#### Пример:

В конфигурации есть список документов **Продажа** со следующими данными:

| Дата     | Склад          | Контрагент | Сумма |
| -------- | -------------- | ---------- | ----- |
| 01.01.19 | Основной       | Корнет ЗАО | 100   |
| 02.01.19 | Основной       | Корнет ЗАО | 200   |
| 03.01.19 | Основной       | Пантера АО | 10    |
| 04.01.19 | Основной       | Пантера АО | 20    |
| 05.01.19 | Дополнительный | Корнет ЗАО | 100   |
| 06.01.19 | Дополнительный | Пантера АО | 10    |


Запрос:

```
ВЫБРАТЬ
	Склад,
	СГРУППИРОВАНОПО(Склад),
	Контрагент,
	СГРУППИРОВАНОПО(Контрагент),
	Сумма(СуммаДокумента)
ИЗ Документ.Продажа
СГРУППИРОВАТЬ ПО ГРУППИРУЮЩИМ НАБОРАМ (Склад, Контрагент)
```


#### Результат:


| Склад          | СГРУППИРОВАНО ПО (Склад) | Контрагент | СГРУППИРОВАНОПО (Контрагент) | Сумма |
| -------------- | ------------------------ | ---------- | ---------------------------- | ----- |
| Основной       | Истина                   | NULL       | Ложь                         | 330   |
| Дополнительный | Истина                   | NULL       | Ложь                         | 110   |
| NULL           | Ложь                     | Корнет ЗАО | Истина                       | 400   |
| NULL           | Ложь                     | Пантера АО | Истина                       | 40    |
