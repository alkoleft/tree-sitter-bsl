# Предложение ИНДЕКСИРОВАТЬ ПО НАБОРАМ полей

При выполнении многократных запросов к одной и той же временной таблице существует возможность создавать несколько индексов временной таблицы по разным полям (наборам полей).

| ИНДЕКСИРОВАТЬ ПО НАБОРАМ ((НаборПолей1)[ ,(НаборПолей2)[,…]]) |                                                     |
| ------------------------------------------------------------- | --------------------------------------------------- |
|                                                               | НАБОР ПОЛЕЙN                                        |
|                                                               | <Разыменование поля> [, <Разыменование поля> [, …]] |

Для каждого набора полей создается отдельный индекс для выбранной временной таблицы. Поля в индексе располагаются в порядке следования полей в наборе.

#### Пример:

> ```
> // индекс временной таблицы строится по наборам полей
> // (Код и Наименование) и АртикулВЫБРАТЬ    Номенклатура.Код КАК Код,    Номенклатура.Наименование КАК Наименование,    Номенклатура.Артикул КАК АртикулПОМЕСТИТЬ ВременнаяТаблицаИЗ    Справочник.Номенклатура КАК НоменклатураИНДЕКСИРОВАТЬ ПО НАБОРАМ (    (Код, Наименование),    (Артикул))
> ```

## Уникальные индексы на временных таблицах

Ключевое слово **УНИКАЛЬНО **в предложении **ИНДЕКСИРОВАТЬ ПО [НАБОРАМ] **позволяет создать уникальный индекс.

Использование индексов позволяет в конкретных случаях повысить производительность выполнения запроса. Индексы можно использовать только для повышения производительности работы временной таблицы и не допускается использовать для контроля уникальности. Следует учитывать, что поведение различных СУБД используемых платформой, в части контроля уникальности может отличаться и, соответственно, при использовании для этой цели уникальных индексов не будет обеспечено корректное решение прикладной задачи.

#### Пример:

> ```
> ВЫБРАТЬ
>     Номенклатура.Код КАК Код,
>     Номенклатура.Наименование КАК Наименование,
>     Номенклатура.Артикул КАК Артикул
> ПОМЕСТИТЬ ВременнаяТаблица
> ИЗ
>     Справочник.Номенклатура КАК Номенклатура
> ИНДЕКСИРОВАТЬ ПО НАБОРАМ (
>     (Код, Наименование) УНИКАЛЬНО,
>     (Артикул)
> )
> ```
