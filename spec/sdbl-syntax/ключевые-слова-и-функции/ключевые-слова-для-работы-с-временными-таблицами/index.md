# Ключевые слова для работы с временными таблицами

Общее описание работы с временными таблицами приведено в разделе.
К работе с временными таблицами относя предложения [ПОМЕСТИТЬ](../../текст-запроса/секция-выбрать-описание-запроса/предложение-поместить/index.md), [ДОБАВИТЬ](../../текст-запроса/секция-выбрать-описание-запроса/предложение-добавить/index.md), [ИНДЕКСИРОВАТЬ ПО](../../текст-запроса/секция-выбрать-описание-запроса/предложение-индексировать-по/index.md) и [ИНДЕКСИРОВАТЬ ПО НАБОРАМ](индексировать-по-наборам/index.md), а также [УНИЧТОЖИТЬ](уничтожить/index.md).
Если во временной таблице необходимо добавить поле со значением, уникальным и последовательно возрастающим в пределах временной таблицы, можно использовать функцию [АВТОНОМЕРЗАПИСИ](../функции/функции-для-работы-с-временными-таблицами/автономерзаписи/index.md).
