# Предложение ИЗ

Задача предложения **ИЗ **состоит в том, чтобы обозначить список исходных таблиц – источников данных (таблицы информационной базы), содержимое которых обрабатывается в запросе. Описание источников может быть опущено только в том случае, если они полностью определены в списке полей выборки.

Следует отметить, что предложение **ИЗ** в языке запросов является опциональным. Оно может быть опущено в том случае, если источники данных полностью квалифицированы в описании списка полей выборки, содержащегося в предложении [ВЫБРАТЬ](../../../текст-запроса/секция-выбрать-описание-запроса/index.md).

После ключевого слова **ИЗ** указывается список источников. В общем случае список источников описывается следующим набором правил:


| <Список источников> |                               |                                                |                                         |                                                                   |                                                                                                                                                                                                                                                                                  |     |
| ------------------- | ----------------------------- | ---------------------------------------------- | --------------------------------------- | ----------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- |
|                     | \|                            |                                                |                                         |                                                                   |                                                                                                                                                                                                                                                                                  |     |
|                     | <Источник>[, <Источник>[, …]] |                                                |                                         |                                                                   |                                                                                                                                                                                                                                                                                  |     |
|                     |                               | \|                                             |                                         |                                                                   |                                                                                                                                                                                                                                                                                  |     |
|                     |                               | <Описание источника> [ <Перечень соединений> ] |                                         |                                                                   |                                                                                                                                                                                                                                                                                  |     |
|                     |                               |                                                | \|                                      | \|                                                                |                                                                                                                                                                                                                                                                                  |     |
|                     |                               |                                                | \|                                      | <Соединение> [<Перечень соединений>]                              |                                                                                                                                                                                                                                                                                  |     |
|                     |                               |                                                | \|                                      |                                                                   | \|                                                                                                                                                                                                                                                                               |     |
|                     |                               |                                                | \|\|\|\|\|\|\|\|                        |                                                                   | [ВНУТРЕННЕЕ] СОЕДИНЕНИЕ <Описание источника>ПО <Условие отбора> \|ЛЕВОЕ [ВНЕШНЕЕ] СОЕДИНЕНИЕ <Описание источника>ПО <Условие отбора> \|ПРАВОЕ [ВНЕШНЕЕ] СОЕДИНЕНИЕ <Описание источника>ПО <Условие отбора> \|ПОЛНОЕ [ВНЕШНЕЕ] СОЕДИНЕНИЕ <Описание источника>ПО <Условие отбора> |     |
|                     |                               |                                                | <Таблица> [[КАК] <Псевдоним источника>] |                                                                   |                                                                                                                                                                                                                                                                                  |     |
|                     |                               |                                                |                                         | \|                                                                |                                                                                                                                                                                                                                                                                  |     |
|                     |                               |                                                |                                         | <Имя таблицы>[(<Параметры>)] \| ( <Описание вложенного запроса> ) |                                                                                                                                                                                                                                                                                  |     |


Источники данных запроса перечисляются в списке источников через запятую. Каждый <Источник> в списке источников обязательно включает в себя описание источника; кроме того, может быть указан <Перечень соединений> – [правила соединений источника с другими источниками](../../../текст-запроса/секция-выбрать-описание-запроса/предложение-из/соединение/index.md).

Если в качестве источника данных выступает таблица информационной базы, <Описание источника> содержит <Имя таблицы>.

Если исходная таблица виртуальная, могут быть указаны <Параметры> ее формирования.

В качестве источника данных запроса может выступать также вложенный запрос; в этом случае описание источника содержит <[Описание вложенного запроса](../../../текст-запроса/секция-выбрать-описание-запроса/предложение-из/описание-вложенного-запроса/index.md)>.

В описании источника данных может быть также назначен его псевдоним. В дальнейшем <[Псевдоним источника](../../../текст-запроса/секция-выбрать-описание-запроса/предложение-из/псевдонимы-источников-данных/index.md)> может использоваться для более удобного обращения к данному источнику.
