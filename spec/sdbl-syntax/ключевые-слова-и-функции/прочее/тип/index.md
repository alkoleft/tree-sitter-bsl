# Литерал типа ТИП

Литерал типа **ТИП** записывается в виде:

> ТИП(<Имя типа>)

<Имя типа> - имя примитивного типа, либо имя таблицы, тип ссылки которой нужно получить.

Результатом данной конструкции будет значение типа [Тип](index.md) для указанного типа.

**Пример**:

```sdbl
ТИП(Строка) // Получение типа "Строка"
ТИП(Справочник.Номенклатура) // Получение типа - ссылка на справочник "Номенклатура"
```

Значения типа [ТИП](index.md) можно в языке запросов можно использовать в операциях сравнения, упорядочивания, группировки.
Пример использования типа в операции сравнения:

```sdbl
ВЫБРАТЬ
          ТИПЗНАЧЕНИЯ(Продажи.Регистратор)
ИЗ
          РегистрНакопления.Продажи КАК Продажи
ГДЕ
          ТИПЗНАЧЕНИЯ(Продажи.Регистратор) = ТИП(Документ.РасходнаяНакладная)
```

Возможна передача значения типа [ТИП](index.md) как параметр запроса.

**Пример**:

```sdbl
ВЫБРАТЬ
          ТИПЗНАЧЕНИЯ(Продажи.Регистратор)
ИЗ
          РегистрНакопления.Продажи КАК Продажи
ГДЕ
          ТИПЗНАЧЕНИЯ(Продажи.Регистратор) = &Тип
```

При сравнении значения типа [ТИП](index.md) значения упорядочиваются в следующем порядке (первый тип считается самым малым):

[NULL](../../константы-и-параметры-значение/null/index.md),

2.

Булево,

4.

5.
[ДАТА](../датавремя/index.md),

6.
[СТРОКА](../../константы-и-параметры-значение/литерал-типа-строка/index.md).
