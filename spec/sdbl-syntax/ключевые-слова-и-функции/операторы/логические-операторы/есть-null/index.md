# Оператор проверки значения на NULL

Оператор **ЕСТЬ NULL** позволяет проверить значение выражения слева от него на [NULL](../../../константы-и-параметры-значение/null/index.md). Если значение равно [NULL](../../../константы-и-параметры-значение/null/index.md) – результатом оператора будет [ИСТИНА](../../../константы-и-параметры-значение/истина/index.md), иначе – [ЛОЖЬ](../../../константы-и-параметры-значение/ложь/index.md). Применение **НЕ** изменяет действие оператора на обратное.

> **см. также: **[Логические выражения](../../../../использование-выражений-в-языке-запросов/логические-выражения/index.md)

#### Пример:

```sdbl
ВЫБРАТЬ
   Справочник.Номенклатура.Наименование,
   Справочник.Номенклатура.ЗакупочнаяЦена
ГДЕ
   Справочник.Номенклатура.ЗакупочнаяЦена Есть NULL
```
