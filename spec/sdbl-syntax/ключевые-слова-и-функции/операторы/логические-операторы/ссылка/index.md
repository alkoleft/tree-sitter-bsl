# Оператор проверки ссылочного значения

Оператор **ССЫЛКА** позволяет проверить, является ли значение выражения, указанного справа от него, ссылкой на таблицу, указанную слева. Если да – результатом оператора будет [ИСТИНА](../../../константы-и-параметры-значение/истина/index.md), иначе – [ЛОЖЬ](../../../константы-и-параметры-значение/ложь/index.md). Разыменование таблиц описано в главе [Разыменование полей](../../../../использование-выражений-в-языке-запросов/разыменование-полей/index.md).

> **см. также: **[Логические выражения](../../../../использование-выражений-в-языке-запросов/логические-выражения/index.md)

#### Пример:

```sdbl
ВЫБРАТЬ
   Справочник.Номенклатура.Наименование,
   Справочник.Номенклатура.ЕдиницаИзмерения
ГДЕ
   Справочник.Номенклатура.ЕдиницаИзмерения ССЫЛКА Справочник.ЕдиницыИзмерения
```
