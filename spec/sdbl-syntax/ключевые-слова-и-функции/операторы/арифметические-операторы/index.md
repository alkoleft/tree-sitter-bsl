# Бинарные операции

Бинарными (арифметическими) операциями являются операции:

> **+ **|** – **|** * **|** /  **

Бинарные операции используются для типов [ЧИСЛО](../../константы-и-параметры-значение/литерал-типа-число/index.md).

Для типа [СТРОКА](../../константы-и-параметры-значение/литерал-типа-строка/index.md) может использоваться бинарная операция **+**.
