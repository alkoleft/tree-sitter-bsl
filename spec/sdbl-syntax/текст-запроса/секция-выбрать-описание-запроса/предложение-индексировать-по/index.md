# Предложение ИНДЕКСИРОВАТЬ ПО

При необходимости создания индекса для временной таблицы следует в запросе указать ключевое слово **ИНДЕКСИРОВАТЬ ПО**, после которого перечислить поля, по которым требуется построить индекс.

Поля, по которым происходит индексирование, должны находиться в списке выборки.

В предложении можно использовать [логические выражения](../../../использование-выражений-в-языке-запросов/логические-выражения/index.md).


Использование индексов позволяет в конкретных случаях повысить производительность выполнения запроса. Индексы можно использовать только для повышения производительности работы временной таблицы и не допускается использовать для контроля уникальности. Следует учитывать, что поведение различных СУБД, используемых платформой, в части контроля уникальности может отличаться и, соответственно, при использовании для этой цели уникальных индексов не будет обеспечено корректное решение прикладной задачи.

#### Пример:

```sdbl
// индекс временной таблицы строится полю Код
ВЫБРАТЬ
    Код,
    Наименование
ПОМЕСТИТЬ ВременнаяТаблица
ИЗ Справочник.Номенклатура
ИНДЕКСИРОВАТЬ ПО Код
          ....
```

Уникальные индексы на временных таблицах
**УНИКАЛЬНО ****ИНДЕКСИРОВАТЬ ПО [НАБОРАМ] **

Примеры:
> ```
> ВЫБРАТЬ    Номенклатура.Наименование КАК Наименование,ПОМЕСТИТЬ ВременнаяТаблица    Справочник.Номенклатура КАК Номенклатура    Код, Наименование УНИКАЛЬНОИНДЕКСИРОВАТЬ ПО     Номенклатура.Код КАК Код,
>     Номенклатура.Артикул КАК Артикул
> ИЗ
> ```
