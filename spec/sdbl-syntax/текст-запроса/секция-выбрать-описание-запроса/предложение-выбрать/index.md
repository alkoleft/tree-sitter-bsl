# Предложение ВЫБРАТЬ

> [ВЫБРАТЬ](index.md) [[РАЗРЕШЕННЫЕ](../../../ключевые-слова-и-функции/общие-ключевые-слова/выбрать/разрешенные/index.md)] [[РАЗЛИЧНЫЕ](../../../ключевые-слова-и-функции/общие-ключевые-слова/выбрать/различные/index.md)] [[ПЕРВЫЕ <Количество>](../../../ключевые-слова-и-функции/общие-ключевые-слова/выбрать/первые/index.md)]
>      <[Список полей выборки](список-полей-выборки/index.md)>

Описание запроса начинается с обязательного ключевого слова **ВЫБРАТЬ**.

Ключевое слово **РАЗРЕШЕННЫЕ** означает, что запрос выберет только те записи, на которые у текущего пользователя есть права.

Данное ключевое слово может присутствовать только в предложении **ВЫБРАТЬ** верхнего уровня и распространяется на весь запрос, включая вложенные запросы.

Если данное слово не указать, то в случае, когда запрос выберет записи, на которые у пользователя нет прав, запрос отработает с ошибкой.

С помощью ключевого слова **РАЗЛИЧНЫЕ** можно указать, что в результат не должны попадать повторяющиеся строки.

В предложении можно использовать [логические выражения](../../../использование-выражений-в-языке-запросов/логические-выражения/index.md).

> **см. также:
> **           [Функция Количество](../../../использование-выражений-в-языке-запросов/агрегатные-функции/количество/index.md)

Предложение **ПЕРВЫЕ <Количество>** позволяет задать предельное количество строк в результате запроса. Будут отобраны самые первые (в соответствии с правилами упорядочивания результатов запроса) строки. <Количество> задается целым числом.

После обязательного ключевого слова **ВЫБРАТЬ** (и уточняющих слов **РАЗРЕШЕННЫЕ**, **РАЗЛИЧНЫЕ** и **ПЕРВЫЕ**) в тексте запроса задается [список полей выборки](список-полей-выборки/index.md).
