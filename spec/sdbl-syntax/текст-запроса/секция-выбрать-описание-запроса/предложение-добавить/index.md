# Добавление новых строк в существующую временную таблицу

Предложение **ДОБАВИТЬ** позволяет добавить новые строки в существующую временную таблицу.
| ВЫБРАТЬ               <Список выборки запроса>,               Таблица.Поле как Поле |                                  |
| ----------------------------------------------------------------------------------- | -------------------------------- |
|                                                                                     | \|                               |
|                                                                                     | ДОБАВИТЬ <Имя временной таблицы> |


**Внимание! **В списке выборки запроса для поля, расположенного непосредственно перед словом **ДОБАВИТЬ**, следует указать псевдоним поля. В противном случае **ДОБАВИТЬ** будет восприниматься как псевдоним поля и при исполнении запроса может быть вызвана ошибка.
Допускается помещать данные в одну временную таблицу, если структура таблицы совпадает.
Порядок записей во временной таблице не гарантируется, может зависеть от используемой СУБД, запроса получения данных из временной таблицы и наличия индексов.

#### Пример:


```
ВЫБРАТЬ    Товары.Наименование КАК НаименованиеПОМЕСТИТЬ ВременнаяТаблицаИЗ    Справочник.Товары КАК Товары; ВЫБРАТЬ    Услуги.Наименование КАК НаименованиеДОБАВИТЬ ВременнаяТаблицаИЗ    Справочник.Услуги КАК Услуги;
```
