# Синтаксис текста запросов

[Текст запроса](текст-запроса/index.md) – это инструкция, в соответствии с которой должен быть выполнен запрос.

В тексте запроса описывается

- таблицы информационной базы, используемые в качестве [источников данных](текст-запроса/секция-выбрать-описание-запроса/предложение-из/index.md) запроса;

- поля таблиц, которые требуется обрабатывать в запросе;

- [правила группировки](текст-запроса/секция-выбрать-описание-запроса/предложение-сгруппировать-по/index.md);

- [сортировки результатов](текст-запроса/секция-упорядочить-по-упорядочивание-результатов/index.md);

- и т. д.

Инструкция составляется на специальном языке – языке запросов и состоит из отдельных частей – секций, предложений, [ключевых слов](двуязычное-представление-ключевых-слов/index.md), [функций](использование-выражений-в-языке-запросов/функции-языка-запросов/index.md), [арифметических](использование-выражений-в-языке-запросов/бинарные-операции/index.md) и [логических](ключевые-слова-и-функции/операторы/логические-операторы/index.md) операторов, [комментариев](комментарии-в-языке-запросов/index.md), [констант и параметров](ключевые-слова-и-функции/константы-и-параметры-значение/index.md).

Cинтаксис языка запросов описывается при помощи [набора правил](синтаксическая-диаграмма-конструкций-языка-запросов/index.md).
